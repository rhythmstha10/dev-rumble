## 🚀 How to Use

### Web Users:
1. Navigate to **Books Catalog** → `/books-page/`
2. Use filter form to search and filter
3. Click "Apply Filters"
4. Results update instantly

### API Developers:
```bash
# Search for books
curl "http://localhost:8000/api/books/?search=Python&available_only=true"

# Track loans
curl "http://localhost:8000/api/circulation/loans/?status=borrowed&ordering=-due_date"

# Manage fines
curl "http://localhost:8000/api/circulation/fines/?is_paid=false&amount_min=50"
```
